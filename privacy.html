Privacy

Last updated: 28 August 2026

FAST GTD is designed to work without an account. Tasks, notes, events and preferences are stored locally by the browser on the device where FAST GTD is used.

Information storage

FAST GTD does not operate a user-account service or require personal information to use the app. Information entered into the app remains in browser storage unless exported, deleted or otherwise shared by the user.

Backups and device changes

Local browser data may be lost if browser storage is cleared, the app is removed or a device is reset. Use FAST GTD’s export feature to create backups and import them when required.

Third-party hosting

The FAST GTD website and app are hosted using GitHub Pages. GitHub may process technical request information under GitHub’s own privacy practices.

Contact

For privacy questions, open an issue in the FAST GTD GitHub repository.

This plain-language statement is a product transparency draft, not legal advice. Review it for the intended launch circumstances.
