# FAST GTD Landing Page, high-quality screenshot edition

This package preserves the original desktop PNG and mobile JPEG and displays both with `object-fit: contain`, so the hero does not crop either interface.

## Publish
1. Create the public repository `fastgtd-site`.
2. Upload every file and folder from this ZIP.
3. In **Settings → Pages**, select **Deploy from a branch**, `main`, and `/ (root)`.
4. Test on desktop and mobile.

## Notes
- The hero uses the complete supplied screenshots.
- The social preview is a separate 1200 × 630 asset because WhatsApp cards require a landscape presentation.
- Review the Privacy draft before launch.
