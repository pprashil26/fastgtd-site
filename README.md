# FAST GTD Landing Page

Upload-ready static GitHub Pages package using the supplied real FAST GTD desktop and mobile screenshots.

## Publish
1. Create the public repository `fastgtd-site`.
2. Upload every file and folder from this ZIP, preserving the structure.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, `main`, and `/ (root)`.
5. Save, then test the published site on desktop and mobile.

Primary launch buttons point to the existing FAST GTD production app.

## Before public launch
- Review the Privacy wording for your circumstances.
- Confirm both screenshots contain no private information.
- Test the WhatsApp preview after the final public URL is available.
- If using a custom domain, add canonical and absolute Open Graph URLs.
