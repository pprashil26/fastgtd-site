# FAST GTD Landing Page

Static landing page for FAST GTD.

## Publish with GitHub Pages
1. Create a public repository named `fastgtd-site`.
2. Upload all files and folders from this package, preserving the structure.
3. Open **Settings → Pages**.
4. Set **Source** to **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.

The primary buttons already point to the production app at `https://pprashil26.github.io/fastgtd/`.

## Before launch
- Replace or approve the privacy wording for your circumstances.
- Replace the SVG social preview with a 1200 × 630 PNG for broader social-platform compatibility.
- Test every link and mobile breakpoint.
- Add a custom domain when ready.
