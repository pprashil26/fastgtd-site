Help

FAST GTD is a compact, local-first system for tasks, notes, events and daily planning.

Start in three steps

  1. Capture: Add a task, note or event as soon as it appears.
  2. Organise: Give tasks the right time horizon and use Areas or Labels for notes.
  3. Review: Check Today and the Planner to decide what deserves attention.

Protect your information

Information is stored locally in the browser. Export a backup regularly, especially before clearing browser data, reinstalling the app or changing devices.

Install the app

Open FAST GTD in a supported browser and use the browser’s install or Add to Home Screen option when available.

Support

For bug reports or suggestions, use the FAST GTD GitHub repository. Include the browser, device and reproduction steps, but do not include private task or note content.
